# Habib Alam — Full Stack MERN Developer Portfolio

A responsive, multi-page dark portfolio built with plain HTML, CSS, and JavaScript.

## Pages
- `index.html` — Home and services
- `about.html` — About and skills
- `projects.html` — Project showcase with category filters
- `contact.html` — Contact form that prepares an email in the visitor's email app

## Run locally
Open `index.html` in your browser, or use VS Code's Live Server extension.

## Before publishing
1. Replace `hello@example.com` in `contact.html` and `js/main.js` with your real email.
2. Update GitHub and LinkedIn URLs in `contact.html`.
3. Replace the illustrative project concepts with your real projects, screenshots, repository links, and live demos.
4. Add your own profile photo if you want one.

No build tools or dependencies are required. Google Fonts are loaded from the web; system sans-serif fallbacks are included.
